# Olá, mundo!

Este é o meu primeiro post usando **MDX** no Next.js.

## O que é MDX?

MDX permite que você use componentes React dentro do seu conteúdo Markdown. Isso abre um mundo de possibilidades para criar posts interativos e ricos.

### Funcionalidades implementadas:

1.  **Capa do post**: Uma imagem bonita no topo.
2.  **Tempo de leitura**: Calculado automaticamente.
3.  **Data do post**: Formatada localmente.
4.  **Idioma**: Suporte para pt e en.
5.  **Tailwind Typography**: Estilização elegante e legível.
